## 1. 铁律（不可违反）

1. **台词必须双语并列**，格式固定为：
   ```
   **角色台词**：角色名（语气，说明）：
   English line here, / with breath marks
   中文台词在此
   ```
   - **第一行英文**，**第二行中文**，两行都套紫色标记：`[[紫|...]]`
   - 说话人标签用 `[[紫|角色名（语气）]]：` 单独一行，放在英文行之前
   - 英文用 `/` 标短换气、`//` 标长停顿（美式口语气口）
   - **英文原文一字不改**，只加气口符号；中文原文一字不改（编辑性拆镜属允许，但字不能动）
   - 内心独白 / 旁白 / 画外音：标签里注明 `OS，内心独白·画外音·嘴唇紧闭` 或 `OS，画外音·低沉·无口型`
   - 无台词的镜头写：`**角色台词**：无台词`

2. **时长铁律**
   - 中文：**4 字/秒**（念出来的）；内心独白/旁白 **5 字/秒**
   - 英文：**3.5 词/秒**（念出来的）；内心独白/旁白 **3.5 词/秒**
   - **双语取较长者**：`需要秒数 = max( ceil(英文词数 ÷ 3.5), ceil(中文当量 ÷ 4或5) )`
   - **单镜头 1-4s，绝不超过 4s**
   - **每段所有镜头之和 ≤ 15s**
   - **该镜头时长 ≥ 本镜头台词所需秒数**（台词必须念得完）
   - 只写 `**预估表演时长**：约Xs`，**不写死精确时间码**

3. **中文当量算法**（用于算中文秒数）：去掉标点后，**汉字按 1 字计**，**拉丁词按音节计**（`Damián`=2、`Eloísa`=3、`Casa Elorza`=5、`Metropolitana`=6）。
   英文词数：按空格切词，忽略 `/`。

4. **标记齐全**
   - 每段**第一个镜头**顶部挂 `[[红|【吸睛开场】⭐]]：[[橙|...]]，[[绿|勾子点：...]]`（段际新起时必挂）
   - 每段**最后一个镜头**顶部挂 `[[红|【结尾钩子】⭐]]：[[橙|...]]，[[绿|勾子点：...]]`
   - **每个镜头**末尾都要有 `[[红|【重点表演】⭐]] [[橙|...]]，[[绿|表演目的：...]]`
   - 标记挂在 `#### 镜头 S-M` 标题行**正下方最上方**（钩子/开场在其它字段之前）

5. **镜头字段顺序固定**：预估表演时长 → 景别 → 运镜 → 画面内容 → 角色台词 → 音效 → 特效 → 【重点表演】⭐

6. **一个镜头只写一种运镜**（角度类可与推拉类组合，不超过 2 种叠加）

7. **颜色标记语法**：只允许 `[[红|文字]]` `[[橙|文字]]` `[[绿|文字]]` `[[紫|文字]]` `[[蓝|文字]]`
   - **竖线 `|` 必须写**
   - 彩色标记内部**不要再套 `**` 加粗**（会冲突）
   - **表格单元格里不要用带竖线的彩色标记**（会拆坏表格）

8. **不得自造台词**。分镜里出现的每一句台词都必须在源稿里能找到。

## 3. 每集要做的五件事

### 3.1 给所有台词加英文（最重要）
逐镜头检查 `**角色台词**`。若只有中文一行 → 按上面格式补成英文一行 + 中文一行。

**英文从哪里来**：从对应的 `_src-第N集.json` 里取 `en` 字段，**原文照抄**。

**难点：分镜把一句长台词拆成了多个镜头** → 英文也要按同样的语义拆开。
做法：
1. 把源 `cn` 按 `，。！？；…` 切成分句，源 `en` 按 `, . ! ? ; —` 切成分句（**两边分句数通常相等**）
2. 找到分镜片段对应源 cn 的哪几个分句
3. 取对应的英文分句，拼成该镜头的英文
4. 全部镜头拼起来应能还原源 en（顺序一致、不漏字）

**若分句数不等**，就按语义手动对齐，务必保证：不漏词、不重复词、语序不乱。

### 3.2 补上漏掉的原文台词
漏句要以**新增镜头**的方式补进去，新镜头要写全所有字段（景别/运镜/画面内容/角色台词/音效/特效/重点表演）。
新镜头要插在**剧情顺序正确的位置**，并与前后镜头动作连贯（站位/光影/动线承接）。

### 3.3 删掉不属于本集的台词 / 自造台词
把镜头改成 `**角色台词**：无台词`（保留镜头，改成纯表演镜，并按无台词重写【重点表演】的表演目的）。
**不要删镜头**（会打乱镜号与段结构）。

### 3.4 重算时长并重排
- 逐镜算 `需要秒数 = max(英文÷3.5, 中文÷4或5)`，把 `**预估表演时长**：约Xs` 改对
  - 无台词镜头按画面动作需要写 1-3s
  - **台词所需 > 4s 的镜头，必须拆成两个镜头**（在台词的气口/标点处拆，英文和中文都在同一处拆开），每个拆出的镜头 ≤4s，各写全字段
- 重排后检查每段：**总时长 ≤15s**。超了就**在本场景的语义断点处拆成两个段**（新段要补：段标题、`## 第一大类`里的【连镜承接】三要素(站位/表演/光影)、人物/场景/道具/故事背景、`## 第二大类`（四行）、`## 第三大类`开头的光影段落与人物站位、段尾小结）
- 拆段后**镜号要全段重编**：`镜头 S-M`（S=段号，M 从 1 重新计数），并把正文里所有 `第X-Y镜`、`镜头X-Y`、`段N` 的交叉引用**同步改对**
- 段标题里的 `约Xs` 必须与 `## 第三大类：画面叙述（分镜头脚本，本段约 Xs）` 里的数字**一致**

### 3.5 同步更新文档头尾
- `## 元信息卡` 里的 **分段**（N 个 15s 分段 ｜ M 个镜头）、**总时长**（约 Xs）、**节奏**（各阶段段号范围）要改对
- `## 📋 导演3.01 最终复查确认` 六项表的说明文字要改成新结构（段数/镜数/总时长/双语核算结论）

## 5. 验收（做完必须自测并把结果贴出来）

```powershell
$ErrorActionPreference='Stop'
function Get-CN([string]$t){
  $punct=@('，','。','！','？','、','；','：','“','”','「','」','（','）','《','》','…','—','·','/','%','．',',','.','!','?',';',':',' ','·')
  $c=$t; foreach($p in $punct){ $c=$c.Replace($p,'') }
  $latin=0;$letters=0
  foreach($m in [regex]::Matches($c,'[A-Za-zÀ-ÿ]+')){
    $w=$m.Value;$letters+=$w.Length
    $s=([regex]::Matches($w.ToLower(),'[aeiouyáéíóúüàèìòùâêîôûäëïöü]+')).Count
    if($s -lt 1){$s=1}
    $latin+=$s
  }
  return (($c.Length-$letters)+$latin)
}
function Get-EN([string]$t){
  $c=$t.Replace('/',' ').Replace('-',' ').Replace([char]0x2014,' ')
  $c=[regex]::Replace($c,"[^A-Za-zÀ-ÿ' ]",' ')
  return (($c -split '\s+' | Where-Object { $_.Trim().Length -gt 0 }).Count)
}
# 把 $f 换成本集 md 路径
$f="E:\Deepseek\开局被鸽\_源文件\0X-分镜脚本-第X集.md"
$lines=[System.IO.File]::ReadAllLines($f,[System.Text.Encoding]::UTF8)
$seg='';$cur='';$d=0;$segTot=0;$shots=0;$grand=0;$bad=0;$okc=0;$maxD=0;$segList=@();$badList=@()
for($i=0;$i -lt $lines.Count;$i++){
  $l=$lines[$i]
  if($l -match '^#\s*段(\d+)'){ if($seg){ $grand+=$segTot; $segList+=("段$seg=$($segTot)s") }; $seg=$Matches[1];$segTot=0 }
  if($l -match '^####\s*镜头\s*(\S+)'){ $cur=$Matches[1];$shots++ }
  if($l -match '预估表演时长.{0,6}约(\d+)s'){ $d=[int]$Matches[1];$segTot+=$d; if($d -gt $maxD){$maxD=$d} }
  if($l -match '^\*\*角色台词\*\*：(.*)$'){
    $m=[regex]::Matches($Matches[1],'\[\[[^\]\|]+\|(.*?)\]\]'); $spk='';$en='';$cn=''
    if($m.Count -ge 2){ $spk=$m[0].Groups[1].Value; $cn=$m[1].Groups[1].Value }
    elseif($m.Count -eq 1){
      $spk=$m[0].Groups[1].Value
      $a=[regex]::Matches($lines[$i+1],'\[\[[^\]\|]+\|(.*?)\]\]'); $b=[regex]::Matches($lines[$i+2],'\[\[[^\]\|]+\|(.*?)\]\]')
      if($a.Count -ge 1){$en=$a[0].Groups[1].Value}; if($b.Count -ge 1){$cn=$b[0].Groups[1].Value}
    }
    if($en -ne '' -and $cn -ne ''){
      $isOS=($spk -match 'OS|VO|旁白|画外音|独白')
      $nCN=[Math]::Ceiling((Get-CN $cn)/$(if($isOS){5}else{4})); $nEN=[Math]::Ceiling((Get-EN $en)/3.5)
      $need=[Math]::Max($nCN,$nEN)
      if($need -gt $d){$bad++; $badList+=("镜{0}: {1}s<需{2}s" -f $cur,$d,$need)} else {$okc++}
    }
  }
}
if($seg){$grand+=$segTot;$segList+=("段$seg=$($segTot)s")}
Write-Host "镜头 $shots ｜ 总时长 ${grand}s ｜ 单镜最长 ${maxD}s"
Write-Host "双语台词镜头：合规 $okc ／ 违规 $bad"
Write-Host ("各段：" + ($segList -join '  '))
$badList | ForEach-Object { Write-Host ("   ✘ " + $_) }
```

**必须全部满足**：
