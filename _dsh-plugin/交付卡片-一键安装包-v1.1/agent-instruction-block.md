## 交付文件卡片（全局约定）

凡本次任务产出的、用户需要拿走的文件（成品文档、表格、脚本包、报告、导出的素材等），**必须**用 `present` 工具声明为交付件——Web 界面会据此在每个回合末尾生成「交付文件卡片」（文件图标 + 说明 + 「打开」按钮）。

- **一次交付、一次声明**：同一任务的全部交付件放在**同一次** `present` 调用里，按主次排序（主件在前）。
- **每张卡片都要写 description**：说清"这是什么 / 版本 / 用途"，用户不打开文件也能看懂。
- **不要把非交付件混进卡片**：备份、中间产物、日志、给助手看的说明笔记一律不要 `present`（可以留在文件夹里，或在正文里提一句路径）。
- **文件先落地再声明**：`present` 只能声明已存在的文件，别用它宣告"计划要生成"的东西。
- **收尾正文里列路径**：在回复中用反引号列出主要交付件的路径，方便点开。
