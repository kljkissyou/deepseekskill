# 表格主题说明（gen-table-xlsx.ps1）

转换器的配色、字体都可以在 JSON 顶层用 `style` 指定；不写就是 **blue 商务蓝**。
本目录下 6 个 `主题样例-*.xlsx` 是**同一张表**分别套 6 套主题的效果，打开挑一个即可。

## 内置主题

| theme | 适合场景 | 表头底 | 表头字 | 隔行底 | 内线 | 外框 |
|---|---|---|---|---|---|---|
| `blue`（默认） | 通用商务交付 | #2F5597 | 白 | #EEF3FA | #BFBFBF | #2F5597 |
| `green` | 自然 / 古风 / 玄幻题材 | #276749 | 白 | #EAF5EE | #C3D6CA | #276749 |
| `graphite` | 正剧 / 沉稳 / 高级灰 | #3B3F46 | 白 | #F2F3F5 | #C9CCD1 | #3B3F46 |
| `warm` | 年代 / 暖调题材 | #9C6B3F | 白 | #FBF3E8 | #DCC9AE | #9C6B3F |
| `red` | 强调 / 警示 / 喜庆题材 | #A61B29 | 白 | #FBEDEE | #E5C5C8 | #A61B29 |
| `print` | 打印 / 黑白复印 | #E8E8E8 | 黑 | 无隔行 | #808080 | #000000 |

## 用法

选一套主题：

```json
{
  "style": { "theme": "green" },
  "sheets": [ { "name": "角色总览表", "widths": [12, 26], "rows": [ ["角色","定位"], ["纪临夜","夜巡队长"] ] } ]
}
```

想微调就在主题基础上覆盖任意一项（只覆盖写出来的键）：

```json
{
  "style": {
    "theme": "blue",
    "fontFamily": "宋体",
    "headerFill": "1F4E79",
    "bandFill": "F4F8FC",
    "outerBorder": "1F4E79",
    "zebra": false,
    "freezeHeader": true
  },
  "sheets": [ ... ]
}
```

| 键 | 说明 |
|---|---|
| `theme` | `blue` / `green` / `graphite` / `warm` / `red` / `print` |
| `fontFamily` | 字体名，默认「微软雅黑」（中文优先） |
| `headerFill` / `headerFontColor` | 表头底色 / 字色 |
| `bandFill` | 隔行浅底色（`zebra` 关掉则无效） |
| `bodyFontColor` | 正文字色 |
| `innerBorder` / `outerBorder` | 内线色（细线）/ 外框色（粗线） |
| `zebra` | 是否隔行底色，默认 `true` |
| `freezeHeader` | 是否冻结表头，默认 `true` |

颜色写 6 位十六进制，带不带 `#` 都行（非法值自动回退默认）。

## 不配置也有的固定排版

- **表头**：加粗、居中、彩色底、白字（`print` 主题为黑字）
- **边框**：外框 `medium` 粗线 + 内部 `thin` 细线（外粗内细）
- **正文**：自动换行、顶端对齐、按内容估算行高（长提示词不裁字）
- **冻结首行**：长表滚动时表头不跑
- **列宽**：由 `sheets[].widths` 指定
