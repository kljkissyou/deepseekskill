# Seedance 2.0 提示词知识库（提示词导演 3.0 版·官方对齐 + 3.0 分段式通用模板）

为「剧本 → Seedance 2.0 文生视频提示词」提供全部参考素材。**v3.0 在 v2.11 基础上采用「导演 3.0 分段式」通用版式**：每个 15s 分段是自包含完整提示词，段内镜头局部编号；文档头部增加元信息卡/连续性锁定/素材配置策略/断句说明，文末增加导演3.0 六项复查；同时保留 1.11（官方《火山方舟 Doubao Seedance 2.0 系列提示词指南》53 页原文逐条对齐）与 1.07/1.10/1.11 全部可用资产。

> 官方指南核心结论：Seedance 2.0 本质是**全模态 AI 导演**——同时读取文字、图片、视频、音频，内部拆成「空间层」（画面里有什么）+「时间层」（事情如何随时间变化）两个维度理解生成。好提示词不是"文案型形容"，而是"工程型指令"：谁、在什么场景、做什么动作、镜头如何运动、按怎样的时间顺序发生。

## 〇、官方三类任务与基础公式（v1.11 官方原文）

根据任务类型选择提示词基础公式：

| 任务 | 定义 | 适用场景 | 推荐句式 |
|---|---|---|---|
| **全模态参考** | 从素材中提取部分元素（主体/风格/场景/音效），生成一个全新视频 | 动作迁移、主体复用、氛围借鉴 | `参考<图片N>中的<主体N>，生成...`；`参考<视频N>中的<动作/运镜/风格/音效>，生成...`；`参考<音频N>中的音色，生成...` |
| **编辑视频** | 在原视频基础上局部/全局修改，未提及部分默认不变 | 局部替换、主体抹除、属性修改 | 增加元素：`清晰描述<元素特征>+<出现时机>+<出现位置>`；修改元素：`严格编辑<视频N>，将其中的<原特征>修改为<新特征>`；删除元素：点明需删除的元素，对保持不变的元素加以强调 |
| **延长视频** | 在时间维度上延续原视频，音视频风格、主体与叙事保持一致 | 续写剧情、延展动作、补全片段 | `向前/向后延长<视频N>`；轨道补全：`<视频1>+<过渡画面描述>+接<视频2>+<过渡>+接<视频3>` |

**⚠️ 指代规则（防误判）**：编辑/延长任务中**直接使用 `<视频N>` 指代视频**；组合任务中以 `参考<视频N>` 指代视频，**请勿直接使用 `<视频N>`，以免被误判为参考任务**。

**⚠️ 参数限制**：轨道补全最多支持 3 段视频输入，总时长不超过 15 秒。

## 一、官方八要素进阶公式（v1.11 官方原文）

```
提示词进阶公式：精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件
```

- **必需**：精准主体、动作细节
- **建议**：场景环境、光影色调、镜头运镜、视觉风格、画质、约束条件

**写作逻辑**：先锁定"谁"在"干什么"，再交代"在哪"、"什么氛围"，然后告诉模型"怎么拍"，最后用风格、画质和约束条件把结果收紧。

| 要素 | 回答的问题 | 写法 |
|---|---|---|
| 精准主体 | 谁？长什么样？ | 用 2-3 个清晰稳定的静态特征定义，确保唯一可识别 |
| 动作细节 | 做什么？幅度/速度/力度？ | 肢体细化 + 程度量化（缓抬手/快速转头/微微低头） |
| 场景环境 | 在哪？什么细节？ | 环境细节 + 时代/地点氛围 |
| 光影色调 | 什么光？什么色调？ | 光线类型 + 色调 + 氛围 |
| 镜头运镜 | 怎么拍？ | 标准运镜术语（中景/特写/缓慢推镜/固定镜头） |
| 视觉风格 | 什么画风？ | 明确风格约束词（赛博朋克冷蓝紫/复古胶片/日系清新） |
| 画质 | 多清晰？ | 高清、细节丰富、电影质感、色彩自然、光影柔和 |
| 约束条件 | 边界在哪？ | 避免字幕/Logo/水印等约束词 |

## 二、主体定义规范（v1.11 官方原文）

1. **基本定义**：`将<图片/视频N>中的[主体核心特征]定义为<主体N>`；核心特征用 **2-3 个清晰、稳定的静态特征**（服饰、发型、外观、类别）描述，确保唯一可识别。示例：`将图片1中穿红色连衣裙、戴草帽的女人定义为主体1`。
2. **多素材同主体**：统一绑定——`将图片1中的□、图片2中的□定义为主体N`。
3. **多主体场景**：分别定义 + **标签区分**（唯一性 + 稳定性），后续描述持续使用对应标签，避免指代混乱。示例：`将视频1中的高个子男人定义为警察，将另一个矮个子男人定义为小偷`，后续持续用"警察""小偷"指代。
4. **每次涉及主体需明确指代，避免省略**，两种用法：
   - 未定义主体的简单场景：每次提到主体都用 `主体N@素材N` 强调绑定关系，如 `张三@图片1`。
   - 已定义主体的场景：每次提到主体都用同一标签。
5. **Asset ID 屏蔽（官方明确）**：使用素材库（Asset ID）时，**仍需使用 `<图片/视频N>` 指代主体**——模型无法直接关联 Asset ID 与参考内容，**不得直接以 Asset ID 替代 `<图片/视频N>`**。
6. 描述尽量简洁、避免冗余、避免歧义冲突（同一主体出现矛盾特征）。
7. **空间关系优先通过参考图表达**，减少复杂文字描述。
8. **不推荐人物多视图/三视图参考**（官方常见问题结论）：多视图含同一人物不同角度，模型易识别为多个不同主体，加剧 ID 漂移；人物参考用 **大头照（仅面部、无表情最佳）+ 全身照** 即可。

## 三、分镜时序规范（v1.11 官方原文·重要修正）

模型内部建模是空间和时间**解耦**的，复杂视频的提示词最理想形态是**时间轴化分镜**：把视频拆成几个分镜，按事件发生顺序动态描述每个分镜——**谁 + 在哪 + 做什么 + 镜头怎么动**。

**⚠️ 精确时间码修正（1.10 → 1.11）**：官方明确——**模型对精确时间（如 0-3 秒）的支持不稳定，强行限制时长可能导致生成结果异常**。因此：

- **分段标注（v3.0 规范 · 3.0 分段式）**：每次「第一大类：基础设定」重新开始 = 一个新的 15 秒 AI 生成分段；每一段都是**自包含的完整提示词**（基础设定 + 氛围画质 + 画面叙述），可单独复制生成；段内镜头重新编号（**镜头 1/2/3…**，不用「镜头1-1/镜头2-1」段号-镜号）；段标题写「# 段N ｜ 主题（场景 · 节奏定位 · 约Xs）」；段尾段首同景接镜；全文跨段引用用「上一段末帧/第X段」，不得出现 T 前缀；
- 分镜条目用 **镜头1 / 镜头2 / 镜头3** 序号组织，按事件发生顺序（先主后次）；
- **不强制限制每段时长**，优先让模型根据剧情自然生成节奏；
- 15 秒/段的制作分段保留在**剪辑层**（每段视频单独生成），提示词文本内**不写死精确秒数**；如需提示节奏，用"约 X 秒·参考时长"等弱提示并注明"时长由剧情自然驱动"。

**每个镜头推荐按以下逻辑组织（四要素）**：
1. **运镜或镜头切换方式**：如"全景缓慢推近""固定机位""镜头切至..."
2. **主体动作与表情**：核心角色/物体的关键动作、神态变化
3. **位置或空间变化**：主体所处场景、位置或空间关系
4. **音频信息**：对应镜头的音效、人声或背景音乐

**正反对照**：
- ❌ 反面："男人在街头紧张地奔跑，画面很有电影感。"（抽象堆砌）
- ✅ 正面：镜头1 街巷侧拍，男人缓慢起跑，带有急促的呼吸感。镜头2 男人撞翻水果摊，镜头快速摇动并给到男人惊恐的特写。镜头3 男人翻过矮墙消失，镜头缓慢拉远定格在空荡的街道。

## 四、动作描述规范（v1.11 官方原文）

1. **肢体细化 + 程度量化**：动作具体到手、腿、头部、肩背等肢体部位，同时补充**幅度、速度、力度**描述。示例：缓抬手、快速转头、用力蹬地、微微低头。
2. **优先低缓连续小动作**：优先缓慢、轻柔、连贯的细微动作，尽量避免狂奔、大跳、剧烈翻滚等高爆发、大动态动作。示例：缓缓行走、轻轻抬手、微微低头、顺势坐下。
3. **补充动作过渡衔接**：写明前后动作的惯性承接关系，保证画面动作连贯自然。示例：借着转身惯性顺势抬手、从停顿状态自然过渡到举手。
4. **情绪具象外化表达**：用具体的身体细节表现情绪，替代"很悲伤""非常愤怒"等抽象词。

| 抽象情绪 | 外化为动作与细节 |
|---|---|
| 悲伤 | 低头、肩膀微微颤抖、眼眶泛红、手指无意识地紧衣角、泪水在眼眶里打转但没有落下 |
| 喜悦 | 嘴角抑制不住地上扬、眉眼舒展、脚步变得轻快、下意识地哼起小曲、忍不住原地转个圈 |
| 紧张/焦虑 | 频繁地看手表、手指不停敲击桌面、呼吸急促、眼神闪躲、无意识地啃咬指甲 |
| 愤怒 | 双拳紧握、下颌线紧绷、胸口剧烈起伏、眼神如刀般锐利、从牙缝里挤出话语 |
| 释然 | 长长地舒了一口气、紧绷的肩膀完全放松下来、脸上露出久违的淡淡的微笑、抬头望向远方 |

## 六、镜头语言：视觉特征写法（保留 1.10）

## 九、素材配置策略（v1.11 官方原文）

把素材分成四种"功能角色"：

1. **角色定妆**：锁定角色外观（人脸特写图/全身照）
2. **场景定调**：锁定环境与风格（场景图）
3. **运镜参考**：锁定镜头语言与动作节奏（运镜视频）
4. **节奏氛围**：用音频控制情绪、音色（音频）

**推荐配置（总计 4-5 个素材）**：角色图 1-2 张（面部特写/全身）+ 场景图 1 张 + 运镜视频 1 段 + 音频 1 段。

**⚠️ 不建议用满素材上限**：过多素材会导致模型难以判断特征优先级，易出现风格冲突、主体识别模糊、生成效果偏离预期。

**重要素材前置**：越需要精准参考的素材，放在提示词中越靠前的位置。

## 十三、英文台词气口断句规则（1.07 第十节，保留）

分镜脚本/提示词文档中，凡涉及英文台词（含海外本土化剧本），一律按以下规则处理，并在文档头部附「断句说明」块：

1. **`/` 为短句换气**：适配日常对话、急促对峙的自然停顿节奏。
2. **`//` 为长停顿换气**：适配情绪转折、愤怒强调、内心 OS 留白的配音节奏。
3. **原文 100% 保留**：所有英文台词保留剧本原文，**无任何单词增删、改写**，仅添加气口分割符；中文译文括号附后，不参与断句。
4. **断句位置**：以句意自然气口为界（标点后、从句与主句间、情绪转折处），长句切成 4-8 词一组；`/` 与 `//` 前后各留一个空格。
5. **时长适配**：英文按约 3-3.5 词/秒估算配音时长，气口符计 0.3-0.5 秒停顿；中文按 4 字/秒估算。

文档头部「断句说明」标准块：

```
断句说明（气口规则）：
1. / 为短句换气，适配日常对话、急促对峙的自然停顿节奏。
2. // 为长停顿换气，适配情绪转折、愤怒强调、内心 OS 留白的配音节奏。
3. 所有英文台词 100% 保留原始剧本原文，无任何单词增删、改写，仅添加气口分割符，适配配音录制节奏。
```

### 镜头字段固定顺序（不可颠倒）

若有段首【吸睛开场】⭐ 或段末【结尾钩子】⭐，先挂在对应镜头上方；随后固定按：
**预估表演时长 → 景别 → 运镜 → 画面内容 → 角色台词 → 音效 → 特效 → 【重点表演】⭐（每镜头必标）**

- **预估表演时长**：约Xs；不写死精确时间码，弱提示即可。
- **景别**：如"轻微仰拍，机器人正面上半身近景""四分之一侧30度微俯拍""牛仔全景"。
- **运镜**：仅 1 种，要交代运镜与主体的关系。
- **画面内容**：细致描写所有细节——动作 + 面部细节 + 呼吸起伏 + 环境交互；面部细节不单独分列；每个动作或每句话都有对应细节；无需服装造型。
- **角色台词**：哪个角色说什么（保留原文 + 语气）；内心独白/旁白 = 画外音、嘴唇紧闭；英文按气口断句。
- **音效**：画面内的环境声/动作声/同期声。
- **特效**：具体的粒子效果（粉尘/火花/光效）。
- **【重点表演】⭐**：重点表演 **本镜头最关键的表演细节**，表演目的：为什么这样演能勾住观众看下去——情绪记忆点/爽点/悬念/反差/钩子。

### 时长计算（硬性铁律）

台词（念出来的）中文按 4 字/秒、英文按 3-3.5 词/秒、内心独白/背景旁白按 5 字/秒（双语取较长者），**逐镜头取整到秒，且该镜头时长必须 ≥ 本镜头台词所需秒数**（台词 16 字 = 4s，绝不允许给 3s）；**单镜头最长 4s、单调镜头 1-4s、绝不允许单一景别镜头超 4s**，台词超 4s 必须拆成多个镜头（在标点/语义断点处切）或做更丰富的运镜延展；每段 ≤15s，段内所有镜头时长之和 ≤15s；连续 OS/旁白跨镜不中断、按总字数算总时长再分摊到各镜。以上为制作层要求，不在最终提示词里区分标注。
