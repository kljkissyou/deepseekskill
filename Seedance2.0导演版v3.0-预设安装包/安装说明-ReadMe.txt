  Seedance 2.0 导演版 v3.0 ｜ 预设安装说明
════════════════════════════════════════════════════════════

【这是什么】
「Seedance 2.0 导演版 v3.0」AI 智能体预设（agent preset）。
装好后，在 DeepSeek Harness / DSH Desktop 新建会话时，
预设选择器中会出现「Seedance 2.0 导演版 v3.0」。

【v3.0 相比 v2.11 的升级】
★ 采用「导演 3.0 分段式 · 通用模板」：
   - 每次「第一大类：基础设定」重新开始 = 一个新 15s AI 生成分段
   - 每一段都是自包含完整提示词（基础设定 + 氛围画质 + 画面叙述）
   - 段内镜头重新编号（镜头 1/2/3…），不用镜头1-1/镜头2-1 段号-镜号
   - 段尾段首同景接镜
★ 最终提示词文档增加通用头部模块：
   - 元信息卡
   - 连续性锁定（全片一致性锚点）
   - 素材配置策略
   - 断句说明
★ 段落与镜头排版升级：
   - 段标题：# 段N ｜ 主题（场景 · 节奏定位 · 约Xs）
   - 段内：第一大类：基础设定 → 第二大类：氛围和画质 → 第三大类：画面叙述
   - 镜头字段改为：预估表演时长/景别/运镜/画面内容/角色台词/音效/特效
   - 每镜头必标【重点表演】⭐，每段首镜【吸睛开场】⭐、末镜【结尾钩子】⭐
★ 文末增加「导演3.0 最终复查确认」：
   - ① 同段内相邻镜头衔接
   - ② 切镜逻辑
   - ③ 站位/光影跨镜承接
   - ④ 台词跨镜完整念完
   - ⑤ 时长合规
   - ⑥ 矛盾/BUG
★ 时长规则通用化：
   - 中文台词 4 字/秒、英文 3-3.5 词/秒、OS/旁白 5 字/秒
   - 双语取较长者；单镜 1-4s；每段 ≤15s

【v2.11 原有特性（完整保留）】
1. 分镜脚本按三大类组织：
   ① 基础设定（【连镜承接】三要素 + 人物/场景/道具/故事背景 + 固定句
      「声音：不需要配乐，仅保留同期声。」）
   ② 氛围和画质（风格核心/视觉基调/色彩与影调）
   ③ 画面叙述（逐镜头七要素）
2. 时长硬性铁律：
   - 台词必须念完；单镜头绝不超过 4s；每段 ≤15s
3. 情绪与表情一致性：人物前后表情情绪一致，
   情绪细节精细到呼吸起伏，面部细节融入画面内容
4. 1.11 官方对齐资产全部保留
5. 物料设定与四文件交付（分镜脚本 .docx / 人物设计参考 .docx+.xlsx /
   场景设计参考 .docx+.xlsx / 服装表 .xlsx）

【一键安装】（Windows，推荐）
右键「安装-到DSH.ps1」→“使用 PowerShell 运行”；
若提示权限不足，脚本会自动请求管理员权限完成安装。
安装后重启 DSH Desktop，预设选择器选「Seedance 2.0 导演版 v3.0」。

【手动安装方法】（Windows）
① 找到目标电脑 DSH_HOME：
   C:\Users\你的用户名\AppData\Roaming\dsh-desktop\harness
② 把整个 seedance-prompter-v300 文件夹复制到：
   <DSH_HOME>\.agent-presets\
   最终路径：
   <DSH_HOME>\.agent-presets\seedance-prompter-v300\
③ 重启 DSH Desktop，新建会话，预设选择器选「Seedance 2.0 导演版 v3.0」。

【macOS / Linux】
   复制到 ~/.dsh/.agent-presets/seedance-prompter-v300/

【注意】
- 目录名 seedance-prompter-v300 就是预设 id，请勿改名。
- 与旧版（v211/v210/v200/v111 等）并存，可在选择器中切换对比。
