# dsh-chinese 分发包（E:\Deepseek）

## 产物清单

| 产物 | 说明 |
|---|---|
| \dsh-chinese/\ | 完整插件目录（推荐安装用） |
| \dsh-chinese-0.1.0.zip\ | 单文件压缩包（传输/归档用） |
| \dsh-chinese-0.1.0.zip.sha256\ | 22.zip 的 SHA-256，用于校验传输完整性 |

## 在其他电脑安装

### 方式一：目录安装（官方，推荐）
把 \dsh-chinese\ 整个文件夹拷贝到目标机，然后：
＾＾＾bat
dsh plugin --profile web add D:\路径\dsh-chinese
＾＾＾
（会自动把它加进 \dsh.profile.bundles\；profile 不是 web 就改名字）

### 方式二：zip
解压 \dsh-chinese-0.1.0.zip\ 得到 \dsh-chinese\ 目录，再按方式一，或运行目录内的 \install.cmd\。

### 方式三：标准 npm tarball（可选）
在有 node/pnpm 的机器上(如本项目打包机)：
＾＾＾bat
cd dsh-chinese
pnpm pack
＾＾＾
会生成 \dsh-chinese-0.1.0.tgz\，其他电脑可 \dsh plugin --profile web add <该.tgz>\。

## 装完
重启 DeepSeek Harness → 新会话自动中文，设置页顶部附近有「中文回复」开关。
卸载：从 profile node_modules 删除 + package.json 移除 bundle 声明，重启。

## 校验
＾＾＾bat
certutil -hashfile dsh-chinese-0.1.0.zip SHA256
＾＾＾
应等于文件 \dsh-chinese-0.1.0.zip.sha256\ 里的值。
